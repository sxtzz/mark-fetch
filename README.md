# Markfetch

> Turn any URL into clean Markdown — no ads, no clutter, just content.

---

## What It Does

**md** extracts the main content from any webpage and converts it to clean, readable Markdown. No ads, no navigation menus, no scripts — just the content you want.

- Paste a URL → get Markdown
- No signup required
- No trackers
- Instant results

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- [defuddle.md API](https://defuddle.md)
